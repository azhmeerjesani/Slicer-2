# Coming from 3D Slicer

Slicer Studio is 3D Slicer with a streamlined interface for tracing lesions and
lesion network mapping. It is built from the 3D Slicer source code, so the
application, its modules, its file formats and its Python interface are the
same. This page says what stays the same, where things moved, and how to get
the classic interface back.

To see it in the application, open the menu (≡, or F10) and choose
**Help > Coming from 3D Slicer…**, or **Help > Take a tour…** for a two-minute
tour of the whole interface. Each step of a tour points at the control on screen
and says how the same thing is done in 3D Slicer.

## What stays the same

- **Files.** Scenes (`.mrml`, `.mrb`) and data (NIfTI, NRRD, `.seg.nrrd`,
  markups, tables) saved by Slicer Studio open in official 3D Slicer 5.12 and
  5.13, and files saved by official 3D Slicer open in Slicer Studio. Studio
  opens files with the same readers.
- **Saving.** Ctrl+S saves the scene with the same Save Data dialog. The lesion
  alone is saved with **Save lesion** in Draw (Ctrl+Shift+S) as a NIfTI mask.
- **Modules and extensions.** Every module is still there; Search (Ctrl+K)
  opens any of them. The Extensions Manager (Ctrl+4) and extensions work as
  usual.
- **Python.** The Python console (Ctrl+3), `slicer.util` and scripted modules
  work unchanged.
- **Views.** The mouse and the keys in the slice and 3D views are the same.
  One addition: in Studio, dragging with the left mouse button adjusts
  window/level when no tool is active.
- **Segment Editor.** Draw is the Segment Editor module with the same effects
  and keys: 1 to 0 pick an effect, Esc deselects it, Space pauses it, Ctrl+Z
  undoes.
- **Settings.** Slicer Studio shares its settings file (`Slicer.ini`) with your
  other 3D Slicer installations. It stores its own choices only under `Studio/`
  and `Appearance/`, and does not change the settings of official 3D Slicer.

## Keyboard differences

The keys of 3D Slicer keep working, except for the few that Studio uses for
its own controls while the Studio interface is shown:

| Key | In 3D Slicer | In Slicer Studio |
| --- | --- | --- |
| Ctrl+K | (not used) | Search |
| Ctrl+F | Module Finder | Search, showing modules |
| Ctrl+H | Home module | Library (Windows and Linux; not on macOS, where ⌘H hides the application) |
| Ctrl+Alt+1, 2, 3 | (not used) | Library, Draw, Map |
| Alt+1 to Alt+4 | (not used) | Layouts: Focus, Single, Four-up, Row |
| Ctrl+\\ or Ctrl+5 | Ctrl+5: show or hide the module panel | Show or hide the inspector |
| F11 or Ctrl+6 | Ctrl+6: Maximize view | Hide panels; Esc shows them again (double-click a view to maximize it) |
| F10 | (not used) | Open the menu (≡) |
| F6, Shift+F6 | (not used) | Move the keyboard focus between the top bar, the inspector and the views |
| Ctrl+Shift+S | (not used) | Save lesion (Draw) |
| Ctrl+Enter | (not used) | The blue button of the inspector (Save lesion in Draw) |
| Ctrl+/ | (not used) | Keyboard shortcuts |
| Esc | Deselects the Segment Editor effect | One step back: closes a popover, leaves Place or window/level mode, restores a maximized view, shows hidden panels, deselects the Draw tool, returns from a module opened with Search |
| Ctrl+Alt+0 | (not used) | Switch to the Classic interface and back |

## Switching to the Classic interface

The Classic interface is 3D Slicer's own interface, exactly as you know it:
the menu bar, the toolbars, the module panel on the left and the status bar.
Switch to it with **≡ > Classic interface** or Ctrl+Alt+0, and back to Studio
with **View > Switch to Studio interface** or Ctrl+Alt+0 again. The scene stays
as it is when you switch. The **Classic interface** link at the bottom of the
Library page does the same.

## Guided tours

The tours are in the menu (≡ > Help):

- **Take a tour…**: Slicer Studio in two minutes.
- **Tour this workspace…**: the Library or Draw workspace (also the
  *Tour this workspace* link of the inspector's ? button).
- **Coming from 3D Slicer…**: what stays the same and what moved, ending with
  the *Where did it go?* list.
- **Where did it go? (3D Slicer → Studio)**: the searchable list above.

The first time Slicer Studio starts, it offers the tour once in a small card;
the offer never blocks anything. Right, Enter or Space go to the next step,
Left goes back and Esc leaves the tour. When a tour ends, Studio puts back the
workspace, the layout and the inspector you had, and the tour never changes
your scene.
